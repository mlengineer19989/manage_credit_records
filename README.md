# manage_credit_records

Google Drive 上のスプレッドシートで管理しているクレジットカード利用履歴を可視化する GAS (Google Apps Script) を管理するリポジトリです。

## 概要

- クレジットカードの利用履歴（スプレッドシート）をもとに、集計・可視化を行う GAS スクリプトを管理します。
- 現状はスプレッドシートに直接紐づいた（コンテナバインド型の）GAS として稼働しています。
- 本リポジトリでは、そのスクリプトをコピーして保存し、変更履歴を Git で管理できるようにします。

## ディレクトリ構成

```
.
├── README.md
└── src/            # GAS のスクリプトファイル（.gs / .js）を配置
    └── .gitkeep
```

- `src/`: スプレッドシートの「拡張機能 > Apps Script」エディタ上にあるファイルをそのままコピー＆ペーストして配置します。
  - `.gs` ファイルはそのまま `.gs` 拡張子で保存してください（例: `Code.gs`, `Aggregate.gs` など、GAS エディタ上のファイル名と揃えると差分管理がしやすいです）。
  - HTML サービスを使っている場合は `.html` ファイルもあわせて配置してください。

## 使い方（現時点）

1. スプレッドシートの Apps Script エディタを開く。
2. 各スクリプトファイルの内容をコピーし、`src/` 配下に同名のファイルとして貼り付けて保存する。
3. 変更をコミットして履歴として残す。

```bash
git add src/
git commit -m "GASスクリプトを追加"
```
